Add MCQ to Question Bank

Import GIFT format text, review MCQs, attach diagram figures, and save to the central bank.
Step 1 — Default Question Details
Step 2 — Import GIFT Format
Use Google Lens to OCR your printed question paper, then lightly edit the text into GIFT format (paste above) or upload a .gift / .txt file. Each question: text + { =correct ~wrong ~wrong ~wrong }
Step 3 — Review, Edit & Attach Images

Edit any field. For diagrams/figures: crop the image in Google Photos, save to device, pick where it belongs (Question or Option A–D), then tap Attach Image. Check "Different class/subject" on a question to override the default metadata for that question only.
